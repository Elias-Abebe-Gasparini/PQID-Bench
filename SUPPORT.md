# Support

Start with the [documentation site](https://elias-abebe-gasparini.github.io/PQID-Bench/)
or the [troubleshooting guide](docs/user-manual/troubleshooting.md).

Use a structured GitHub issue for:

- a reproducible software defect;
- an unclear or missing documentation step;
- a possible benchmark-evidence or evaluator-integrity problem.

Questions about the manuscript's scientific interpretation should identify the
specific metric, denominator, table, or artifact involved. Questions about a
third-party provider should include the route, HTTP status, and sanitized error
message, but never an API key or complete sensitive response.

Security issues must not be reported publicly. Follow [SECURITY.md](SECURITY.md).
