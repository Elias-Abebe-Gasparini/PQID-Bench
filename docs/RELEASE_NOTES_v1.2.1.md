# `pqid-bench` v1.2.1

Release date: 2026-07-31

Version 1.2.1 is a documentation and package-metadata clarification. It does
not change the frozen PQID-Bench v1.0.0 scientific object or the behavior of
the Python toolkit.

## Reader-Facing Ecosystem Map

The package long description and documentation now identify the correct entry
point for each common task:

- PyPI supplies the installable CLI and Python API;
- Hugging Face supplies the ready-to-use benchmark records and compact core;
- Zenodo preserves the completed study's full evidence and audit archive;
- GitHub supplies maintained source, tests, manuals, and development history;
- GHCR supplies the isolated evaluator container; and
- OSF preserves the prospective PQID-Bench 2 study contract.

## Prospective-Study Boundary

The documentation now explains that an OSF preregistration is an immutable,
timestamped plan recorded before the relevant outcomes are collected.
PQID-Bench 2 is a separate two-stage future study of semantic validity and
controlled quantum-algorithm family contrasts. No PQID-Bench 2 model output or
result is part of PQID-Bench v1.0.0.

The current research supplement's **O6** label means Overview object 6. It is a
cross-reference to the OSF protocol, not another analytical table or current
benchmark result.
