# Code of Conduct

## Our Standard

PQID-Bench is a scientific software project. Participants are expected to be
respectful, precise, evidence-aware, and constructive. Examples of welcome
conduct include:

- discussing methods and results without attacking people;
- distinguishing defects, disagreements, and research-integrity concerns;
- acknowledging uncertainty, provenance, and prior work;
- making the project accessible to contributors with different levels of
  quantum-computing and software experience.

Harassment, discriminatory language, intimidation, deliberate disclosure of
private information, credential sharing, and knowingly misleading scientific
claims are unacceptable.

## Scope and Enforcement

This standard applies in repository issues, pull requests, discussions,
documentation contributions, and other project spaces. Maintainers may edit,
remove, or reject contributions and may restrict participation when behavior
threatens people, project security, or scientific integrity.

Report conduct concerns privately through the repository owner's GitHub profile.
Report software vulnerabilities through the process in
[SECURITY.md](SECURITY.md). Reports will be handled with discretion and without
retaliation.
